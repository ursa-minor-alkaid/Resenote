# 实验操作预习

## 功能定义

在实验操作之前，针对目标实验检索入门级教程内容，生成独立的 Markdown 预习文件，覆盖实验介绍、实验器材与材料、实验操作步骤三个核心板块，用于操作前的知识准备，降低实际上手难度。本功能只做「检索预习资料并生成预习文件」这一件事，不修改任何已有笔记或文献文件。

激活：自然语言表达同义，如「预习一下小鼠腹腔注射」「为脑立体定位注射实验准备预习资料」。

用户未提供的信息以自然语言提问确认，不得自行猜测：

- **实验主题**：未给出（只写 `-exptpre`，或表述中无法确定具体实验）时，询问实验名称
- **来源笔记**：用户要求以某份笔记为准但未给出路径时，询问笔记文件或笔记文件夹路径；路径指向文件夹时，先列出其中的笔记并确认目标
- **信息冲突**：笔记内容与用户给出的实验主题不一致时，确认后继续
- **保存目录**：无法确定时询问保存目录（确定规则见「输出规范」）

---

## 检索规则

### 检索目标

只检索目标实验的入门级教程内容，围绕实验目的、基本原理、器材与材料、操作流程、入门注意事项组织检索。

### 来源优先级

1. **教学类来源**：高校课程网站与实验教学中心、公开课讲义、实验 protocol 库（如 protocols.io、Bio-protocol）
2. **教材与手册类来源**：实验指导书、仪器或试剂厂商公开的操作手册章节
3. **科普与百科类来源**：仅用于补充背景理解与术语解释，不作为操作步骤的依据

### 过滤规则

命中结果满足以下任一条时不采用：

- 晦涩、专精的研究性文献：单篇原始研究论文、方法学前沿文章、机制探讨类论文
- 需要订阅、登录或无法公开访问的内容
- 来源不明、内容农场、批量生成、论坛零散发言（论坛内容仅作线索，需与权威来源交叉验证一致后才可用）
- 与目标实验无关，或仅在关键词层面命中的结果

### 检索式构造

- 中文检索：`{实验名称}` 搭配 `实验 / 操作 / 步骤 / 原理 / 教程 / 入门`
- 英文检索：使用该实验的国际通用名称，搭配 `protocol / tutorial / step-by-step / guide / introduction`
- 优先使用入门词（入门、教学、教程、introduction、tutorial），避免使用研究性术语（mechanism、signaling pathway 之类）

### 准确性要求

- 关键原理与操作步骤需在两个及以上独立来源中一致；出现分歧时以教学类、教材类来源为准，并在文档中给出简短说明
- 检索不到可靠资料的部分如实留空或不写，在反馈中说明，不得编造
- 不得虚构器材规格、试剂浓度、操作参数、文献信息

## 内容提取与文件生成逻辑

1. 从命中的教学资源中提取四类信息：实验目的、基本原理、器材与材料清单、操作步骤
2. 按三个核心板块组织内容，写入新建的 Markdown 文件
3. 生成前核对每个板块的内容是否有检索来源支撑，无支撑的内容不写入
4. 生成后向用户反馈：采用的来源、内容缺失或存在分歧的部分、需要进一步查阅的位置

### 三个核心板块

**1. 实验介绍**

- 分点列出实验目的、基本原理、重要性
- 面向初次接触该实验的读者，术语首次出现时给出简短解释
- 控制在 3~5 条

**2. 实验器材与材料**

按设备、工具、耗材与试剂三类列出：

- 只列主要项，常见基础物品（水、酒精、吸头之类）可省略
- 每项用一句话说明规格或用途，不展开原理

**3. 实验操作步骤**

- 使用 Markdown 有序列表（`1. ` 等）按操作顺序编号
- 有归属关系的步骤使用嵌套列表
- 每条步骤一句话，操作要点与提醒直接写在步骤内
- 步骤按实际实验流程编写，不做人为合并与删减

### 精炼要求

- 面向预习场景，不写研究背景综述，不堆砌文献引用，不展开机制讨论
- 三个板块合计篇幅以 800~1200 字为宜

---

## 输出规范

- 生成独立的 Markdown 文件，命名为 `{实验名称}-预习.md`
- 保存位置：提供了来源笔记时与来源笔记同目录；用户指定了其他目录时按指定目录；无法确定时向用户询问，不得自行猜测
- 文件标题为 `# {实验名称}-预习`，标题下一行写日期行（格式见输出模板）：`日期：{今日日期（如，2026年9月20日）}`
- 三个核心板块使用二级标题，编号为 `## 1. 实验介绍`、`## 2. 实验器材与材料`、`## 3. 实验操作步骤`
- 文末附简短的「参考资料」列表，不超过 5 条，只列来源名称与标题，供核实使用
- 不修改任何已有文件

---

## 注意事项

1. **禁止编造**：操作步骤、器材规格、试剂浓度、原理表述、文献信息均须来自实际检索结果
2. **来源可核实**：只采用公开可访问的教学类、教材类来源，百科与科普内容不作为操作依据
3. **精炼优先**：预习文件面向操作前快速阅读，内容超出必要范围时删减，不做扩展
4. **与笔记冲突时的处理**：预习资料与来源笔记中的记录不一致时，以笔记内容为准，并在反馈中说明差异
5. **零改动**：不修改任何已有笔记、文献或原始文件
6. **不确定时确认**：实验主题、保存目录无法确定时向用户询问，不得猜测
